### Featured AI Project

**Secure Multilingual Enterprise AI Assistant**

I designed and developed a multilingual **RAG-based AI assistant** for enterprise document search and question answering.

The system includes:

`Document Ingestion → Preprocessing → Semantic Chunking → Embeddings → Vector Search → Context Retrieval → LLM → Grounded Response`

The system supports **French, Arabic, and English** and was designed for **on-premises deployment**, using local LLM inference with vLLM and Qdrant for vector search.

This project gave me practical experience with the complete **RAG pipeline**, AI backend development, semantic retrieval, LLM inference, and secure AI deployment.
